05 — Build note

Build note · how the form is wired

The form is HTML, not an embed

A static site on GitHub Pages has no server, so a working form needs somebody else’s endpoint. The question is when that endpoint gets contacted. The form above is plain HTML posting to Web3Forms: nothing is fetched from another domain until you press Send — no script, no iframe, no cookie, nothing at page load. Open the Network tab and read this page; you will see requests to one domain, this one.

An embedded form — a Google Form in an iframe is the usual one — would load a third party on every render of this page, set cookies before anyone had agreed to anything, and could not be styled to match the site. That is the version this page does not have.

There is no email-obfuscation script either: a plain mailto link is more accessible, works with JavaScript turned off, and opens in whatever the reader already uses.
